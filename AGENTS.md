# Instructions for Codex

This repository is a modified fork of Postiz and must remain AGPL-compliant.

Rules:
1. Do not delete or alter LICENSE files, copyright notices, or attribution notices unless you first explain why.
2. Keep legally required license/compliance text intact.
3. Never place real API keys, passwords, or secrets into the repository.
4. Use `.env.example` for placeholders only.
5. If adding a hosted-app footer or settings page, include a visible "Source Code" link for AGPL compliance.
6. Before changing branding, first identify all branding-related files.
7. Before changing environment/configuration, first identify which variables are required and what they do.
8. Explain all steps in beginner-friendly language.
9. Prefer small, reviewable changes with a list of edited files.
